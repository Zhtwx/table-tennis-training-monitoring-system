# table-tennis-training-monitoring-system

乒乓球运动员综合训练监控管理系统。

## 快速启动

Windows 下双击：

```text
run_server.bat
```

或在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe app.py
```

访问：

```text
http://localhost:5000
```

## 默认账号

| 身份 | 用户名 | 密码 |
|---|---|---|
| 管理员 | `admin` | `admin123` |
| 普通用户 | `coach` | `user123` |
